# Reneo SIDesa (`sidesa-services`)

Sistem Informasi Desa (SID) dan Website Resmi Desa multi-tenant yang berjalan sebagai layanan terpadu di **Reneo Panel** (`ghcr.io/aknalre/sidesa-services:latest`).

## Modul Utama
- **Portal Publik Desa**: Beranda, Profil Desa, Pemerintahan (SOTK), Infografis (Penduduk, APBDes, Bansos + Cek Bansos, IDM/Indeks Desa, Stunting, SDGs), Layanan Surat Mandiri & Pelacakan, Berita Desa, Beli Dari Desa (UMKM), PPID (UU KIP), Pengaduan Masyarakat, Peta Desa (POI), Potensi, Wisata, dan Galeri.
- **Back-Office Pemerintahan Desa (`/admin`)**: Kependudukan (Permendagri 47/2016), Pelayanan & Cetak Persuratan (Permendagri 109/2019), APBDes, Bansos, PBB-P2, Absensi/Buku Tamu, PPID, Pengaduan, Berita, UMKM, dan Profil Desa.
- **Integrasi Opsional WAHA Reneo**: Notifikasi WhatsApp otomatis saat status surat atau pengaduan warga diperbarui.
